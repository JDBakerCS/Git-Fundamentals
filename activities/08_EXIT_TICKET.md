# Activity 08 — Exit Ticket

Complete individually without copying commands from a partner.

## Evidence commands

```text
git status
git branch --show-current
git log --oneline --decorate -5
git remote -v
```

## Short answers

1. A file is saved but not staged. Where does the change live?
2. A commit exists locally but is missing on GitHub. What operation is probably missing?
3. Why should a reviewer open **Files changed** rather than approve from the PR title?
4. What does a merge conflict ask a human to decide?
5. After a teammate’s PR is merged, what should you do to update your local `main`?

## Final success check

- [ ] My working tree is clean or I can explain every remaining change.
- [ ] I can identify my current branch.
- [ ] I can show one commit I created.
- [ ] I can show one Pull Request I authored or reviewed.
- [ ] I can explain one error I encountered and the evidence I used to fix it.

# Activity 00 — Pre-class Check

Complete before the lecture if possible.

## Tools

- [ ] Git is installed.
- [ ] VS Code is installed.
- [ ] You can sign in to GitHub.
- [ ] You received the class repository URL.

## Identity check

Run in the VS Code terminal:

```text
git --version
git config --global user.name
git config --global user.email
```

## Success evidence

- Git prints a version.
- Your name and email are not blank.
- You can open the class repository in a browser.

If any check fails, take a screenshot or copy the exact error message for the instructor. Do not share passwords or access tokens.
